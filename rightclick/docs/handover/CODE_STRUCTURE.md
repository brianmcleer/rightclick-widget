# Code structure

## Files

| File | What it holds |
|---|---|
| `manifest.json` | Widget name, version, `exbVersion`, translated locales. |
| `config.json` | Default configuration for a newly added widget. |
| `src/config.ts` | The configuration types (`IMConfig`), defaults, and pure helpers shared by runtime and settings: `customActionMatchesLayer`, `computeLayerSelectionKey`, `parseWktInfo`, `normalizeWkt`, feature layer validation. No Experience Builder or Maps SDK imports, so it is unit tested directly. |
| `src/runtime/widget.tsx` | The whole runtime: one function component. See the table below. |
| `src/runtime/components/HelpPopup.tsx` | The shared help guide dialog. Copied unchanged between GIS Division widgets; do not edit here. |
| `src/runtime/components/Dialogs.tsx` | `TextInputDialog` (Add Text) and `MailingLabelsBufferDialog`, both jimu-ui `Modal`s. Strings arrive as props. |
| `src/runtime/helpSections.ts` | Builds the help guide sections from feature flags. The only help file that is specific to this widget. |
| `src/runtime/theme.ts` | `useTokens()`: theme colors, radii and shadows. Copied unchanged between widgets. |
| `src/runtime/i18n-t.ts` | `__t`, `__tc`, `__locale`: translation outside the React tree. Generated by exb-i18n-kit. |
| `src/runtime/translations/default.ts` | Every runtime string (English). The other locale files are generated. |
| `src/setting/setting.tsx` | The settings panel, including the XML import and export. |
| `src/setting/translations/default.ts` | Every settings string (English). |
| `src/shared/beacon.ts` | Anonymous usage and error telemetry. Shared module, synced from the family master. |
| `src/exb-editor-shims.d.ts`, `src/vendor-shims.d.ts` | Visual Studio type shims. Editor only; left out of the release zip. |
| `tests/` | Node test runner suites and their loader. No dependencies. |
| `docs/` | This documentation. |
| `i18n/` | exb-i18n-kit status and lock files. |

## Configuration keys

All in `src/config.ts` (`IMConfig`). Every key is optional except `useMapWidgetIds`.

| Key | Controls |
|---|---|
| `useMapWidgetIds` | The connected map widget. |
| `enabledActions` | One switch per built-in menu row. |
| `menuSettings` | Address header, number hotkeys, "More coordinate formats". |
| `showHelp` | The Help button in the menu header. Undefined means on. |
| `copySettings` | Coordinate system and format for Copy Coordinates; `importedSystems` holds the coordinate systems imported from `.prj` files. |
| `plotSettings`, `markerSettings`, `textSettings` | Look of plotted coordinates, simple markers and text. |
| `measurementSettings` | Default units, single or dual display. |
| `longPressSettings` | Touch press-and-hold: on or off, duration, movement tolerance. |
| `reverseGeocodeUrl`, `reverseGeocodeWkid` | Address lookup service. |
| `pictometryUrl` | Enables the Pictometry row. |
| `whatsHereSettings`, `uiSettings`, `whatsHereLayerSelection`, `whatsHereHighlight`, `featureLayers`, `popupOverrides` | What's Here: search radius and limits, popup layout, which layers take part, highlight symbol, extra feature services, Arcade popup overrides. |
| `propertyReportSettings`, `mailingLabelsSettings` | Target widget and container for the two launch rows. |
| `customActions` | Rows added by the app author. |
| `telemetry` | `false` turns the beacon off for the app. |

## How the menu gets its rows

`getMenuItems()` builds the list on every render from config and the current
`state.contextMenu`. Each row has an `action` string; `handleContextMenuAction(action)`
runs it. Prefixed actions carry an id: `custom:<id>` (custom actions) and `copy-crs:<id>`
(imported coordinate systems). Values that need an asynchronous projection are computed
when the menu opens and stored in state, because the clipboard only works inside the
click's own call stack.
